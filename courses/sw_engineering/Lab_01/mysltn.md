1. Software Development Life Cycle
  1.1 Planning
     The project team determines what functionality students need.
  1.2 Analysis
     Software architects define the components and interfaces of the system.
  1.3 Design
  1.4 Implementation
     Developers implement the connection search algorithm.
  1.5 Testing & Integration
     Testers check whether the complete application fulfills its specified requirements.
     The application is released to the university app store.
     Students test whether the application satisfies their expectations.
  1.6 Maintenance
     Developers fix defects and adapt the application after its release.
